## Reading my messages

Not every message is a request for work. Before using a tool, decide which kind this is:

- **Question**: answer it. Read files only if the answer depends on them. Change nothing.
- **Comment, opinion, reaction**: reply. No tools.
- **Answer to a question you asked**: acknowledge it, say what you'd do next, and stop.
  An answer to "which way?" is a decision, not a go-ahead.
- **Instruction** ("do X", "fix Y", "go", "build it"): do it.

If it's unclear which kind it is, treat it as discussion.

Stopping costs me one word to restart you. Unrequested work costs me noticing, interrupting,
and cleaning up. A memory save on a discussion turn is fine; it never leads into other work.
