# Standup

Answer the three standup questions from what I actually did, not from
memory. Everything is read-only except the `## Standup` section of today's
daily note. Don't transition tickets, comment, post to Slack or touch any
repo.

"Yesterday" means the previous workday: Friday on a Monday. Use local dates.

**Work only.** Engram and the vault mix work and personal life. An item
belongs in the standup only if it ties to work:

- a Jira ticket,
- a repo under `~/src/forgecloud/` or a PR in a work GitHub org,
- a vault `working/` project or engram project for work: `alert`,
  `fedramp`, `fraas`, `idx_team`, `inc`, `infrastructure`, `tf-env-saas`,
  `tf-env-saas-v2`, or one named after a Jira key.

Leave out everything else: my own tooling (dotfiles, `workbench`, anything
under `~/src/thoreinstein/`), `self-review` (yearly review notes), finances,
health, kitchen, YNAB, games. When unsure, leave it out. Don't mention what
was left out.

## 1. Gather

Use every source that is available. If one fails (not authenticated, server
down, tool missing), skip it, keep going, and list it at the end. Don't ask
for things you can look up.

- **Engram.** `mem_context` and `mem_search` for sessions, decisions,
  bugfixes and open threads from yesterday. Search across projects, not just
  the current one.
- **Jira.** Use the Jira MCP's `searchJiraIssuesUsingJql`:
  - My sprint: `assignee = currentUser() AND sprint in openSprints() ORDER BY status`
  - Moved yesterday: `assignee = currentUser() AND updated >= "<yesterday>" AND updated < "<today>"`
  - Blocked: `assignee = currentUser() AND sprint in openSprints() AND (flagged is not EMPTY OR status = Blocked)`.
    Also check issue links for an open "is blocked by".
- **GitHub.** `gh search prs --author @me --updated ">=<yesterday>"` and
  `gh search prs --reviewed-by @me --updated ">=<yesterday>"`, plus my open PRs
  waiting on review (`gh search prs --author @me --state open --review required`).
- **Local git.** My commits from yesterday across work repos:
  ```bash
  for r in ~/src/forgecloud/*/; do
    git -C "$r" log --all --oneline --author="$(git -C "$r" config user.email)" \
      --since="<yesterday> 00:00" --until="<today> 00:00" 2>/dev/null | sed "s|^|$(basename "$r"): |"
  done
  ```
- **Vault.** Yesterday's `Daily/YYYY/MM/YYYY-MM-DD.md` (read it with
  `obsidian_read_note`), and `obsidian_rag_query` with `after` set to
  yesterday for `working/` notes touched since then.
- **Calendar.** Today's work meetings, if a work calendar is available.
  They shape how much of today is free for ticket work. Ignore personal
  calendars and events.

## 2. Draft

Three sections. Bullets, one line each, ticket keys and PR numbers inline.
Merge duplicates: a commit, a PR and a ticket for the same work are one
bullet. Write in plain sentences I can read aloud, not terse or abbreviated.

- **Yesterday.** What got done or moved forward, grouped by ticket or
  project. Leave out busywork (formatting, config churn) unless it was most
  of the day.
- **Today.** In-progress sprint tickets first, then the next to-do tickets,
  then open threads from engram. Mention big meetings in one line.
- **Blockers.** Flagged or Blocked tickets, open "is blocked by" links, my
  PRs waiting on review for more than a day, open threads that say they're
  waiting on someone. Say who or what each is waiting on. If there are none,
  write "None".

Mark anything you inferred rather than read (for example, a "today" item
guessed from an open thread) with "(guess)".

## 3. Print and save

Print the standup in chat, then the list of skipped sources, if any.

Then save it to today's daily note, `Daily/YYYY/MM/YYYY-MM-DD.md`:

```markdown
## Standup

### Yesterday
- ...

### Today
- ...

### Blockers
- ...
```

- If the note has a `## Standup` section, replace it.
- If the note exists without one, insert the section right after the
  `# YYYY-MM-DD` title.
- If the note doesn't exist, create it with this frontmatter and title, then
  the section:
  ```markdown
  ---
  type: daily
  created: YYYY-MM-DD
  ---

  # YYYY-MM-DD
  ```

`## Standup` is the only part of a daily note you may write. The rest is
generated by `engram-daily-log`, which keeps this section when it rewrites
the note. Use `###` for subheadings inside it: the next `##` heading ends
the section.
